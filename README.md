# Phonebook Manager

`Phonebook Manager`는 C 언어와 NCURSES 라이브러리를 사용한 전화번호부 관리 프로그램입니다.
프로그램은 `data.txt` 파일에서 전화번호 데이터를 읽어 오고, 실행 중에 검색, 추가, 삭제, 전체 목록 보기 기능을 제공합니다.
프로그램 종료 시 현재 전화번호부 내용을 다시 `data.txt`에 저장합니다.

실행 파일 이름은 과제 요구사항에 맞게 `tel`입니다.

## Source Files

- `tel.c`: 프로그램 시작점입니다. 실행 인자 확인, 데이터 로드, UI 실행, 종료 시 저장을 담당합니다.
- `phonebook.c`, `phonebook.h`: 전화번호부 자료구조, 동적 배열 관리, 파일 입출력, 검색 기능을 담당합니다.
- `ui.c`, `ui.h`: NCURSES 초기화, 메뉴 화면, 검색/추가/삭제/list 화면을 담당합니다.
- `data.txt`: 전화번호부 데이터 파일입니다.
- `wiki/`: 코드 구조와 구현 흐름을 설명하는 wiki 문서입니다.

## Main Data Structures

연락처 한 명은 `Contact` 구조체에 저장합니다.

```c
typedef struct {
    char name[30];
    char phone[20];
    char memo[100];
} Contact;
```

전체 전화번호부는 `PhoneBook` 구조체에 저장합니다.

```c
typedef struct {
    Contact *items;
    size_t count;
    size_t capacity;
} PhoneBook;
```

`items`는 동적으로 할당되는 배열입니다. 처음에는 128개 저장 공간을 만들고, 공간이 부족하면 2배씩 늘립니다.
따라서 최소 100개 이상의 엔트리를 저장할 수 있으며, 고정된 최대 개수 제한을 두지 않았습니다.

검색 결과는 연락처를 복사하지 않고 `IndexList`에 원본 배열의 인덱스만 저장합니다.
이 방식은 메모리 낭비가 적고, 검색 결과에서 원래 연락처 번호를 바로 표시하기 쉽습니다.

## Build

아래 명령으로 컴파일합니다.

```sh
cc -Wall -Wextra -pedantic -std=c11 -o tel tel.c phonebook.c ui.c -lncurses
```

성공하면 실행 파일 `tel`이 생성됩니다.

## Run

아래 명령으로 프로그램을 실행합니다.

```sh
./tel
```

실행하면 NCURSES 기반 메뉴가 열립니다.

## Menu

메인 메뉴에는 다음 기능이 있습니다.

1. `Search`: 이름, 전화번호, 메모에서 검색어를 포함하는 연락처를 찾습니다. 대소문자는 구분하지 않습니다.
2. `Add`: 이름, 전화번호, 메모를 입력해 새 연락처를 추가합니다.
3. `Delete`: 목록에서 연락처를 선택한 뒤 삭제합니다. 삭제 전 확인 질문을 합니다.
4. `List`: 전체 연락처 목록을 보여줍니다.
5. `Save and Exit`: 현재 데이터를 저장하고 종료합니다.

## Controls

- `UP`, `DOWN`: 메뉴 또는 목록에서 위아래로 이동합니다.
- `ENTER`: 선택한 기능을 실행합니다.
- `1`부터 `5`: 메인 메뉴에서 기능을 바로 선택합니다.
- `q` 또는 `ESC`: 이전 화면으로 돌아가거나 저장 후 종료합니다.
- `HOME`, `END`: 목록 화면에서 처음 또는 마지막 항목으로 이동합니다.
- 검색 결과 화면에서 `n`: 새 검색을 시작합니다.

## Data Format

각 줄은 콜론(`:`)으로 구분합니다.

```txt
Lee:01098765432:G777
Baek:01062773268:C516
Jung:0222871111:Goodman
```

필드 순서는 다음과 같습니다.

```txt
name:phone:memo
```

예시처럼 memo가 비어 있는 데이터도 허용합니다.

```txt
Kim:01023450987:
```

단, 콜론(`:`)은 필드 구분자로 사용되므로 이름, 전화번호, 메모 입력값 안에는 사용할 수 없습니다.
프로그램에서 새 연락처를 추가할 때 콜론이 들어가면 저장하지 않고 안내 메시지를 출력합니다.

## Implementation Notes

- 파일 로드는 `load_contacts()`에서 처리합니다.
- 파일 저장은 `save_contacts()`에서 처리합니다.
- 추가는 `add_contact()`에서 처리합니다.
- 삭제는 `delete_contact()`에서 처리합니다.
- 검색은 `build_search_results()`에서 처리합니다.
- 화면 출력과 키 입력 처리는 `ui.c`에 모았습니다.

`load_contacts()`에서는 `strtok()` 대신 `strchr()`로 콜론 위치를 직접 찾습니다.
이유는 `Kim:01023450987:`처럼 마지막 memo 필드가 비어 있는 줄도 올바르게 읽기 위해서입니다.

목록 화면과 삭제 화면은 터미널 높이에 맞춰 한 화면에 보이는 줄 수를 계산합니다.
선택한 항목이 화면 밖으로 나가면 `top` 값을 조정해서 스크롤처럼 보이게 만들었습니다.
