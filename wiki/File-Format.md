# File Format

전화번호부 데이터는 `data.txt` 파일에 저장됩니다.

## 기본 형식

각 줄은 연락처 한 명을 의미합니다.
필드는 콜론(`:`)으로 구분합니다.

```txt
name:phone:memo
```

예시는 다음과 같습니다.

```txt
Lee:01098765432:G777
Baek:01062773268:C516
Jung:0222871111:Goodman
Kim:01023450987:
```

## 빈 memo 허용

마지막 필드인 memo는 비어 있을 수 있습니다.

```txt
Kim:01023450987:
```

이 경우 이름은 `Kim`, 전화번호는 `01023450987`, 메모는 빈 문자열로 처리됩니다.

## 콜론 제한

콜론은 필드 구분자로 사용됩니다.
그래서 이름, 전화번호, 메모 안에는 콜론을 넣을 수 없습니다.

프로그램에서 연락처를 추가할 때 입력값에 콜론이 들어 있으면 저장하지 않고 안내 메시지를 출력합니다.

## 파일 로드 방식

`load_contacts()`는 한 줄씩 읽은 뒤 `strchr()`로 첫 번째 콜론과 두 번째 콜론을 찾습니다.

`strtok()`를 사용하지 않은 이유는 마지막 memo 필드가 비어 있는 줄을 정확히 처리하기 위해서입니다.
예를 들어 `Kim:01023450987:` 같은 줄은 마지막 값이 비어 있지만 유효한 데이터입니다.

## 파일 저장 방식

`save_contacts()`는 현재 메모리에 있는 전체 연락처를 `data.txt`에 다시 씁니다.
파일을 덮어쓰기 모드로 열기 때문에 삭제된 연락처가 파일에 남지 않습니다.
