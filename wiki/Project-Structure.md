# Project Structure

프로젝트는 기능별로 파일을 분리했습니다.
단일 `tel.c`에 모든 코드를 넣지 않고, 자료 처리와 UI 처리를 분리해 읽기 쉽게 만들었습니다.

## 파일 목록

| 파일 | 역할 |
| --- | --- |
| `tel.c` | 프로그램 시작점 |
| `phonebook.h` | 전화번호부 자료구조와 함수 선언 |
| `phonebook.c` | 연락처 추가, 삭제, 검색, 파일 입출력 |
| `ui.h` | UI 실행 함수 선언 |
| `ui.c` | NCURSES 메뉴와 화면 처리 |
| `data.txt` | 연락처 데이터 저장 파일 |
| `README.md` | 사용자용 설명 문서 |
| `wiki/` | 코드 설명용 wiki 문서 |

## 의존 관계

```txt
tel.c
 ├─ phonebook.h
 └─ ui.h

ui.c
 ├─ ui.h
 └─ phonebook.h

phonebook.c
 └─ phonebook.h
```

`tel.c`는 프로그램의 큰 흐름만 담당합니다.
실제 연락처 데이터 처리는 `phonebook.c`가 맡고, 화면 처리는 `ui.c`가 맡습니다.

## 분리한 이유

- 코드 길이를 줄이고 파일별 역할을 명확히 하기 위함
- 자료구조 로직과 화면 로직이 섞이지 않게 하기 위함
- 함수 위치를 쉽게 찾을 수 있게 하기 위함
- 추후 기능 추가 시 수정 범위를 줄이기 위함
