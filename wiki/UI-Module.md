# UI Module

`ui.c`와 `ui.h`는 NCURSES 기반 화면과 사용자 입력을 담당합니다.

## 담당 기능

- NCURSES 초기화
- 메인 메뉴 출력
- 검색 화면 출력
- 추가 화면 출력
- 삭제 화면 출력
- 전체 목록 화면 출력
- 방향키, 숫자키, Enter, q, ESC 입력 처리

## UI 시작 함수

```c
void run_phonebook_ui(PhoneBook *book, int loaded);
```

이 함수는 NCURSES를 초기화하고 메인 메뉴를 실행합니다.
UI가 끝나면 `endwin()`을 호출해 터미널 상태를 복구합니다.

## 메인 메뉴

메인 메뉴에는 다음 항목이 있습니다.

1. Search
2. Add
3. Delete
4. List
5. Save and Exit

사용자는 방향키로 이동하거나 숫자키 `1`부터 `5`까지 눌러 바로 선택할 수 있습니다.

## 입력 처리

`prompt_text()`는 사용자에게 문자열을 입력받는 공통 함수입니다.

주요 처리 내용은 다음과 같습니다.

- 입력 전 화면 제목 출력
- 입력 버퍼 초기화
- `getnstr()`로 최대 길이를 제한해 입력 받음
- 앞뒤 공백 제거
- 필수 입력값이 비어 있으면 다시 입력 요청

## 목록 스크롤

목록 화면은 터미널 높이에 맞춰 한 번에 보여줄 수 있는 줄 수를 계산합니다.

```c
int visible = LINES - 8;
```

`selected`는 현재 선택한 항목이고, `top`은 화면 맨 위에 보이는 항목의 인덱스입니다.
선택한 항목이 화면 밖으로 나가면 `top`을 조정해 스크롤처럼 보이게 합니다.

## 검색 화면

검색 화면은 `build_search_results()`로 얻은 인덱스 목록을 사용합니다.
검색 결과에는 연락처 전체가 아니라 원본 배열의 인덱스만 들어 있습니다.
따라서 화면에 출력할 때는 `book->items[contact_index]`로 다시 원본 연락처를 가져옵니다.

## 추가 화면

추가 화면에서는 이름, 전화번호, 메모를 순서대로 입력받습니다.

콜론(`:`)은 `data.txt`의 필드 구분자이므로 입력값 안에 있으면 저장하지 않습니다.
연락처 추가가 성공하면 바로 `save_contacts()`를 호출해 파일에 저장합니다.

## 삭제 화면

삭제 화면에서는 연락처를 선택한 뒤 `ENTER` 또는 `d`를 누르면 삭제 확인 화면이 나옵니다.
사용자가 `y`를 누른 경우에만 실제 삭제합니다.

마지막 항목을 삭제한 경우 선택 위치가 배열 범위를 벗어나지 않도록 조정합니다.
